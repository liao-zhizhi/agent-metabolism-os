local-first · MIT

Audit your own agents locally. Zero data leaves your machine. 上面这块大屏是云端展示；真正的审计跑在你自己的机器上，判据、见证、账本都在本地进程里。

01

安装 sidecar

pip install "git+https://github.com/liao-zhizhi/harness-audit-sidecar.git"

PyPI 上尚未发布，所以上面的命令走 git，今天就能装。 发布后命令会简化为 pip install harness-audit-sidecar。 装完应该有一个可执行文件： harness-audit-server --help。

02

接进 Cursor / Claude（MCP）

展开 mcp_config.json 配置 
{
  "mcpServers": {
    "harness-audit": {
      "command": "harness-audit-server",
      "args": ["--cwd", "/absolute/path/to/your/project", "--quiet"]
    }
  }
}
  • --cwd 必须写被审计项目的绝对路径，不是 sidecar 自己的目录。
  • 结论写进 audit_trace.jsonl；不要从 stdout 取判决，那里只有 Agent 被允许看到的东西。
  • 账本默认就在项目目录里。如果被审计的 Agent 能写这个目录，它也能删——需要抗篡改就指向它写不到的位置。
