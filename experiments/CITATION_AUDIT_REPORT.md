## Reproducing

```
python3 -m experiments.citation_audit_report            # use the cached run
python3 -m experiments.citation_audit_report --refresh  # re-query arXiv and CrossRef
python3 -m experiments.citation_audit_report --check    # exit 1 on any FAIL
```

Network is touched only by `--refresh` (or by a first run with no cache). The auditor's own rule is inherited here: an unreachable agency yields `INVALID`, never `FAIL`.
